Part 1: Domain Controller

Description

Deploying and configuring the primary Domain Controller for the TUP–Taguig domain. Design domain layout, OU structure, and initial roles.

  • Domain Controller (tupt.edu.ph)
  • Set time zone
  • Add roles → Active Directory Domain Services → add required features → install
  • Click "close this wizard and launch ADCSIW"
  • Create a new domain in a new forest
  • Name: tupt.edu.ph
  • Forest functional level: WS 2008
  • Set Directory Services Restore Mode password
  • Wait for installation
  • Finish
