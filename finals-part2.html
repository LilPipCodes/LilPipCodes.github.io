  • Create domain users for each department/office and technology section. Use their real names when creating the domain account.
  • Create an organizational unit for each technology section or office (e.g., computer engineering, electronics, registrar, research, etc.).
  • All users can only log on to workstations (XP class A network, 7 class B network) that were assigned to their respective departments/offices:
    • Users → Properties → Computer Restrictions → select which computer
  • All users should change their passwords every 30 days:
    • Go to Group Policy Management → create a GPO for the org unit Academic & Administrative
    • For academic: Academic Password | For Administrative: Administrative Password
    • Click Edit → Computer Config → Security Settings → Account Policies → Password Policies → Maximum Password Age → Properties → 30 days → Apply → OK
  • Academic users can log on from 7:30 AM - 8:45 AM while administrative staff users can log on from 7:00 AM - 7:00 PM:
    • Select Users in each Department in academic → Properties → Account → Check "Log on hours" and select time range then log on permitted
