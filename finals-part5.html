Part 5: RAID

Description

Implement RAID configurations for redundancy and performance in the server environment. Apply security baseline policies and deploy scripts via GPO.

Overview

Install and configure the following RAID levels:

  • RAID 0: Striped Volume
  • RAID 1: Mirrored Volume
  • Spanned Volume
  • RAID 5: Parity Volume

Step 1-4: Prepare Virtual Hard Disks

  1. Clone Windows Server 2008 used for DHCP activity
  2. After cloning, click Settings → Storage → click add attachment icon → Hard Disk
  3. In medium selector:
    Click Create
    Check "Pre-allocate full size"
    Allocate size: 50 MB
    Click Finish
  4. Repeat steps 2-3 to create 10 total hard disks

Step 5-9: Attach Disks and Initialize

  1. Back to Settings → Storage → Attach all 10 hard disks to WS2008
  2. Start WS2008
  3. Click Start → Administrative Tools → Server Manager
  4. Expand Storage → Click Disk Management
  5. An "Initialize Disk" dialog box will appear showing all attached disks
  6. Ensure partition style is set to MBR
  7. Click OK to initialize all disks
  8. After initialization: You will see Disk 0 (main VM storage) plus 10 additional disks (Disk 1-10) ready for RAID configuration.

RAID 0: Striped Volume

  1. Right-click Disk 1 → Select "New Striped Volume"
  2. Configuration wizard appears:
    Click Next
    Select Disk 2 → Click Add
    Click Next → Next
    Volume name: RAID0 or striped
    Check "Perform a quick format"
    Click Next → Finish
  3. If a confirmation prompt appears, click Yes
  4. Wait for volume creation to complete

RAID 1: Mirrored Volume

  1. Right-click Disk 3 → Select "New Mirrored Volume"
  2. Configuration wizard appears:
    Click Next
    Select Disk 4 → Click Add
    Click Next → Next
    Volume name: RAID1 or mirrored
    Check "Perform a quick format"
    Click Next → Finish
  3. If a confirmation prompt appears, click Yes
  4. Wait for volume creation to complete

Spanned Volume

  1. Right-click Disk 5 → Select "New Spanned Volume"
  2. Configuration wizard appears:
    Click Next
    Select Disk 6 → Click Add
    Select Disk 7 → Click Add
    Click Next → Next
    Volume name: spanned
    Check "Perform a quick format"
    Click Next → Finish
  3. If a confirmation prompt appears, click Yes
  4. Wait for volume creation to complete

RAID 5: Parity Volume

  1. Right-click Disk 8 → Select "New RAID 5 Volume"
  2. Configuration wizard appears:
    Click Next
    Select Disk 9 → Click Add
    Select Disk 10 → Click Add
    Click Next → Next
    Volume name: RAID5
    Check "Perform a quick format"
    Click Next → Finish
  3. If a confirmation prompt appears, click Yes
  4. Wait for volume creation to complete

✓ RAID Installation Complete

  • RAID0: Striped volume using Disk 1-2 for improved performance
  • RAID1: Mirrored volume using Disk 3-4 for fault tolerance
  • Spanned: Spanned volume using Disk 5-7 for increased capacity
  • RAID5: Parity volume using Disk 8-10 for balanced performance and fault tolerance
