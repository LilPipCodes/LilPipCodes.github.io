Activity 3: DHCP Joining Workstation in Domain

Description

𐙚 ‧₊˚ ⋅ III. DHCP Role & Joining Workstations to Domain
This activity focuses on installing and configuring a DHCP Server, setting up network scopes for different student groups, and connecting client computers to the domain. It ensures proper IP address assignment and domain connectivity for Windows XP and Windows 7 clients.

  • Role Installed: DHCP Server
  • Network Scopes:
    • Class A Network: 10.0.0.0 /8 (Male students)
    • Class B Network: 172.16.0.0 /16 (Female students)
  • Additional Settings:
    • Server IP: Last usable IP address
    • Exclusion: First & Last 10 usable IP addresses
    • Lease Time: 16 hours
    • Router: Server IP Address
    • DNS: Server IP Address & 8.8.8.8
  • Client Systems Created:
    • Windows XP – LASTNAME-XP
    • Windows 7 – LASTNAME-WIN7
  • Requirements:
    • Windows XP must receive Class A IP Address
    • Windows 7 must receive Class B IP Address
    • Login 5 student accounts per section per OS
