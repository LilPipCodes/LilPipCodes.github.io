Part 6: Remote Desktop

Description

Configure Remote Desktop services for remote administration and secure access. Design backup schedules and verify recovery procedures.

Prerequisites

  • Start Windows XP VM
  • Start Windows 7 VM
  • Start Windows Server 2008 VM

Enable Remote Desktop on Windows 7

  1. Open Active Directory Users & Computers (on Windows Server 2008)
  2. Navigate to Computers container
  3. Find and open your Windows 7 computer object
  4. Right-click Windows 7 → Computer Properties
  5. Go to Remote Settings tab
  6. Check the option: Allow connections from running any version of Remote Desktop
  7. Click Apply → OK

Connect to Windows 7 from Windows Server 2008

  1. On Windows Server 2008, search for: Remote Desktop Connection
  2. Open Remote Desktop Connection application
  3. Enter the computer name/hostname of your Windows 7 machine
  4. Click Connect
  5. Enter Windows 7 user credentials and password
  6. Wait for connection to establish
  7. A confirmation prompt will appear on Windows 7 VM asking to accept connection
  8. On Windows 7, click OK to accept
  9. Windows Server 2008 now has remote access to Windows 7 desktop

✓ Windows 7 Remote Desktop Connection Established

Enable Remote Desktop on Windows XP

  1. On Windows XP VM, right-click My Computer
  2. Select Properties
  3. Go to Remote tab
  4. Verify that Allow users to connect remotely to this computer is checked
  5. Click OK

Connect to Windows XP from Windows Server 2008

  1. Important: Log off Windows XP first (do NOT stay logged in)
  2. On Windows Server 2008, search for: Remote Desktop Connection
  3. Open Remote Desktop Connection application
  4. Enter the computer name/hostname of your Windows XP machine
  5. Click Connect
  6. A confirmation prompt appears on Windows XP
  7. Click Yes to accept
  8. Enter Windows XP user credentials
  9. Windows Server 2008 now has remote access to Windows XP desktop

⚠ Important Reminder: Always log off from Windows XP before attempting to connect via Remote Desktop Connection. You cannot have the same user logged in simultaneously on both local console and remote connection.

Verification

  • ✓ Remote Desktop Setup Complete
  • Windows Server 2008 can now:
    • Remote connect to Windows 7 via Remote Desktop
    • Remote connect to Windows XP via Remote Desktop
    • Manage both client workstations remotely
    • Access all resources and applications on remote machines
