Part 3: DHCP Server

Description

Configure DHCP services, scopes, and reservations to provide network addressing for the domain. Configure network roles and ensure clients receive proper settings.

DHCP Server Requirements

  • IP Block: 172.31.0.0 /16 & 10.0.0.0 /8
  • Router IP address is valid IP address
  • DNS server IP address: Same as DHCP server + Google (8.8.8.8, 8.8.4.4) & OpenDNS (208.67.222.222, 208.67.220.220)
  • IP address lease expires every 8 hours
  • Do NOT distribute first 30 and last 30 valid IP addresses

Setup Steps

  1. Clone Windows Server 2008
  2. Clone Windows 7 & XP
  3. Select WS2008 → Settings → Network → Change Adapter 1 & 2 to Internal Network
  4. Configure WS2008 Network:
    • Go to WS2008 settings → Network → Rename Adapter 1 as "XPFEMALENET"
    • Rename Adapter 2 as "7MALENET"
  5. Go to WSXP settings → Network → Rename Adapter 1 as "XPFEMALENET"
  6. Go to WS7 settings → Network → Rename Adapter 1 as "7MALENET"
  7. Start WS2008
  8. Configure Networking: Control Panel → Network & Internet → Network Connections → Change Adapter Settings → Right click LAN → Properties
  9. Set IPv4 Properties:
    • Local Area Connection 1 (Female):
      IP: 172.31.0.31
      Subnet: 255.255.255.0
      Gateway: 172.31.0.32
      Preferred DNS: 127.0.0.1
    • Local Area Connection 2 (Male):
      IP: 10.0.0.31
      Subnet: 255.0.0.0
      Gateway: 10.0.0.32
      Preferred DNS: 127.0.0.1
  10. Add DHCP Server Role: Start → Administrative Tools → Server Manager → Roles → Add Roles → Select DHCP SERVER
  11. Validate settings and install DHCP
  12. Open DHCP: Start → Administrative Tools → DHCP
  13. Create New Scopes:
    • Class A Female-XP Scope:
      Scope Name: Class A Female-XP
      Start IP: 172.31.0.1 | End IP: 172.31.0.254
      Subnet Mask: 255.255.255.0
      Exclusions: 172.31.0.1-30 (first 30) & 172.31.0.225-254 (last 30)
      Duration: 8 hours
      Default Gateway: 172.31.0.32
      Domain: tupt.edu.ph
    • Class B Male-7 Scope:
      Scope Name: Class B Male-7
      Start IP: 10.0.0.1 | End IP: 10.0.0.254
      Subnet Mask: 255.0.0.0
      Exclusions: 10.0.0.1-30 (first 30) & 10.0.0.225-254 (last 30)
      Duration: 8 hours
      Default Gateway: 10.0.0.32
      Domain: tupt.edu.ph
  14. Configure DNS Servers for both scopes (Remove 127.0.0.1):
    • Primary DNS: 8.8.8.8 (Google)
    • Secondary DNS: 8.8.4.4 (Google)
    • Tertiary DNS: 208.67.222.222 (OpenDNS)
    • Quaternary DNS: 208.67.220.220 (OpenDNS)
  15. Configuring Windows XP
    • Start Windows XP VM while keeping Windows Server 2008 running
    • Rename computer: START → Right click My Computer → Properties → Computer Name → Change → "LASTNAME_CS-XP" (e.g., ESPINAR_CS-XP)
    • Join domain: Domain: tupt.edu.ph → Click OK
    • Enter credentials:
      Username: Administrator
      Password: (Your WS2008 admin password)
    • Welcome message appears → Click OK → Restart
    • Log in with Administrator account (TUPT\\administrator) and test with another domain user
  16. Configuring Windows 7
    • Repeat all steps from Windows XP configuration but with Windows 7
    • Rename computer as: "LASTNAME_CS-WIN7"
    • Join domain: tupt.edu.ph with same credentials
    • Log in as TUPT\\administrator and test with another domain user
  17. Connecting Windows XP & 7 using DHCP
    • Start WS2008, WXP & W7
    • Check Address Leases: WS2008 → Start → Administrative Tools → DHCP → Expand Domain → Expand IPv4 → Click Address Leases
    • Class B Male network should show W7 connected
    • Class A Female network should show WXP connected
    • Verify on W7: Command Prompt → ipconfig /all
      DHCP should be enabled with IP from Class B Male network
    • Verify on WXP with same command (should show Class A Female IP)
  18. Troubleshooting: Domain Connection Errors
    • If error "Cannot connect to your domain controller" occurs:
    • Verify DHCP → Class A or B → Scope Options → 006 DNS Servers has NO 127.0.0.1
    • On Windows XP or Windows 7, run in Command Prompt:
      • ipconfig /release
      • ipconfig /renew
      • ipconfig /all
    • Verify DNS servers in ipconfig output match scope options
    • Attempt to reconnect to domain
