Part 8: Group Policies

Description

Design and deploy Group Policy Objects to standardize configuration and security across clients. Implement basic monitoring and define incident response steps.

YouTube Tutorial

Step-by-Step Group Policy Implementation

I. Department-Specific Desktop Wallpaper

  1. For each department, create a GPO (e.g., ACADEMIC WALLPAPER).
  2. Navigate to: User Configuration → Policies → Administrative Templates → Desktop → Desktop → Desktop Wallpaper.
  3. Edit the policy: Enable → Wallpaper Name: (Path of the Wallpaper) → Apply → OK.
  4. Repeat for each department with their respective wallpaper.

II. Restrict/Disable the Following via GPOs

  • Create two GPOs in the domain: Users Policy and Admin Policy.
  • If in User Policy: Enable | If in Admin Policy: Disable

Users Policy Settings

  1. Enable: Prohibit access to Control Panel and PC settings
    User Configuration → Policies → Admin Templates → Control Panel
  2. Enable: Network security: Do not store LAN manager hash value on next password change
    Computer Configuration → Policies → Windows Settings → Security Settings → Local Policies → Security Options
  3. Enable: Prevent access to the command prompt
    User Configuration → Policies → Admin Templates → System
  4. Enable: No auto-restart with logged on users for scheduled automatic updates installations
    Computer Configuration → Policies → Admin Templates → Windows Components → Windows Update
  5. Enable: All removable storage classes: Deny all access
    Computer Configuration → Policies → Admin Templates → System → Removable Storage Access
  6. Enable: Prohibit user install
    Computer Configuration → Policies → Admin Templates → Windows Components → Windows Installer
  7. Disable: Accounts: Guest account status
    Computer Configuration → Policies → Windows Settings → Security Settings → Account Policies → Security Options
  8. Set minimum password length to at least 12 characters
    Computer Configuration → Policies → Windows Settings → Security Settings → Local Policies → Password Policy
  9. Set maximum password age to 42 days
    Computer Configuration → Policies → Windows Settings → Security Settings → Local Policies → Password Policy
  10. Enable: Audit directory service access (success)
    Computer Configuration → Policies → Windows Settings → Security Settings → Local Policies → Audit Policy
  11. Set account lockout duration: 30 minutes
    Computer Configuration → Policies → Windows Settings → Security Settings → Account Policies → Account Lockout Policy
  12. Set account lockout threshold: 3 invalid logon attempts
    Computer Configuration → Policies → Windows Settings → Security Settings → Account Policies → Account Lockout Policy
  13. Reset account lockout counter after: 30 minutes
    Computer Configuration → Policies → Windows Settings → Security Settings → Account Policies → Account Lockout Policy
  14. Remove links and access to Windows Update
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  15. Remove network connections from the Start Menu
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  16. Remove Help menu from the Start Menu
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  17. Remove Run menu from the Start Menu
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  18. Remove My Pictures icon menu from the Start Menu
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  19. Remove My Music icon menu from the Start Menu
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  20. Remove My Network Places icon menu from the Start Menu
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  21. Add Logoff on the Start Menu: Enable
    User Configuration → Policies → Admin Templates → Network → Start Menu and Taskbar
  22. Remove Task Manager from Ctrl+Alt+Del
    User Configuration → Policies → Admin Templates → System → Ctrl+Alt+Del Options
  23. Internet Explorer browser title: Title bar text: <domain name>
    User Configuration → Policies → Windows Settings → Internet Explorer Maintenance → Browser User Interface
  24. Prohibit access to properties of components of a LAN connection
    User Configuration → Policies → Admin Templates → Network → Network Connections
  25. Prevent access to the command prompt
    User Configuration → Policies → Admin Templates → System
  26. Prevent access to registry editing tools
    User Configuration → Policies → Admin Templates → System
  27. Prohibit access to the Control Panel
    User Configuration → Policies → Admin Templates → Control Panel

Note: For each setting, Enable in User Policy and Disable in Admin Policy as required.
