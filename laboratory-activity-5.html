Description

Group Policy Management
We configure Group Policy Objects (GPOs) to manage system restrictions and security policies.
✦ Implemented Policies:
• Remove Windows Update accessLogoff to Start Menu
• Disable Task Manager (CTRL+ALT+DEL)
• Customize Internet Explorer Title Bar
• Restrict LAN Connection Properties
• Prevent access to:
⦁ Command Prompt
⦁ Registry Editor
⦁ Control Panel
Admin accounts retain full control, while users are restricted.
